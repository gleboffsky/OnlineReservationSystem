# OnlineReservationSystem

Console reservation system: routes and schedules are loaded from text files,
seats are booked with a linked-list model.

## Features

- Read routes and schedule from `route.txt` / `schedule.txt`
- Search routes, book and cancel seats
- Custom containers (linked lists) with manual memory management

## Stack

C++ (STL), Visual Studio, no external dependencies.

## Build

Open `OnlineReservationSystem.sln`, build and run the console application.

```
OnlineReservationSystem\route.txt
OnlineReservationSystem\schedule.txt
```
